Какие данные собираются?

Имя и возраст пациента, село/махалля, жалоба со слов пациента, записанные медсестрой объективные наблюдения осмотра и симулированные или снятые с ESP32 показания датчиков.

Для чего?

Только для демонстрации офлайн-записи и синхронизации с врачом в прототипе для хакатона.

Где хранятся данные?

Записи хранятся локально в IndexedDB браузера. После запуска синхронизации медсестрой они отправляются настроенному backend и, если подключён, Telegram-боту.
